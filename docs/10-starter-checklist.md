# Chapter 10 — The Starter Checklist

Time: two minutes to read, a season to live with. Tools: a printer, a pencil. This is the whole book compressed into one page — hang it next to the coffee, tape it inside a cabinet door, and let the checkboxes do the remembering.

It is organized the way the book is: one evening at a time, with the *keep-alive* rituals at the bottom, since habits are the part that outlives setup. Each box has its chapter's back-reference so a stuck box knows where to reread.

## Before anything (chapter 1)

- [ ] Green list written: the two or three jobs the server is *for* — files, photos, wiki, site (1)
- [ ] Each potential job passed the four reachability questions — "who can reach it, from where, with what" (1)
- [ ] Any yellow ideas parked with a date; email and strangers'-data jobs confirmed staying in the cloud (1)

## Choosing and preparing the device (chapters 2–3)

- [ ] Spare device chosen — laptop, mini PC, or Pi — with its **one quiet job** named (2)
- [ ] If old laptop: wiped per the Old Laptop Revival Guide's backup-first rule; if Pi: SD card flashed per the Pi guide (2)
- [ ] Linux installed (laptop install day lives in the Old Laptop Revival Guide, ch. 4) (2)
- [ ] Updates ran once, and the **monthly five-minute update** has a date on the calendar (3)
- [ ] Machine named (`family-server`) and ping-verified by name (3)
- [ ] Router DHCP reservation set — current address pinned forever (3)
- [ ] Sleep cure done — lid-close: nothing; idle: never (3)
- [ ] `server-notes.txt` created: name, address, flavor, update command, and a line per fix (3)
- [ ] Server password is unique and in your password manager (3)

## The private lane (chapter 4)

- [ ] VPN lane app installed on the server; `tailscale status` (or equivalent) shows it green (4)
- [ ] One phone reached the server from *somewhere else* — coffee shop, porch, anywhere away (4)
- [ ] Whole family's devices on the member list; strangers: none (4)
- [ ] Port forwarding page remains unopened — the lane means strangers never see the door (4)

## The family's data (chapter 5)

- [ ] Family folder tree planned — `documents`, `school`, `projects`; rename later = tax paid (5)
- [ ] File sync working laptop ↔ server ↔ second laptop, live (5)
- [ ] Camera-roll path chosen and working — photo library app, or plain folders (5)
- [ ] Family briefed: deletes delete *everywhere*; two-devices-same-time makes a "conflicted" copy (5)
- [ ] Phone background upload confirmed working, at least for the Android half of the house (5)
- [ ] iPhone expectation set if relevant: photos back up on wifi/charge, politely (5)

## The family wiki (chapter 6)

- [ ] Wiki chosen: folder of notes, or DokuWiki on the server (6)
- [ ] Five starter pages live: wifi-and-guests, recipes, house manual, repairs-and-people, how-the-server-works (6)
- [ ] At least one non-you family member has edited a page (6)
- [ ] The reflex phrase agreed: repeated chat answers also go to their wiki page (6)

## The little website (chapter 7)

- [ ] Site written in Markdown and built to HTML (7)
- [ ] Built files copied to the server; visible in a browser on the lane (7)
- [ ] Audience decided on purpose: family-via-lane, public-by-bridge, or free static host for the world (7)
- [ ] Site **sources** added to the backup list — the writing is the irreplaceable part (7)

## Backups, before the first goodbye (chapter 8)

- [ ] "Would anyone cry" list written and short (8)
- [ ] USB drive backup ran, with a dated folder (8)
- [ ] One real file deleted and restored from the drive, by hand, once (8)
- [ ] Offsite copy exists: relative's synced laptop, or modest cloud tier for the irreplaceable subset (8)
- [ ] Seasonal restore rehearsal on the calendar, three years of sad-face slots (8)

## The keep-alive rituals

Shorter than the setup, infinitely more important:

- [ ] **Monthly, ~5 minutes:** run updates; skim the wiki; glance at SYNC still being SYNC; note anything in `server-notes.txt` (3, 6)
- [ ] **Seasonally, ~10 minutes:** restore rehearsal; lane member-list check; drive shelf date (4, 8)
- [ ] **Yearly, one evening:** the whole checklist, re-read; anything grayed out gets deleted, anything dreamed gets parked with a date (this page)
- [ ] **Someday, guilt-free:** — reread [chapter 9](09-when-plain-cloud-is-better.md) whenever a new job arrives; the honest answer is allowed to be "cloud"

A finished box is a small landed thing. A homelab with eight checked boxes and a working lane is already ahead of the household you started with — print it, and let it grow at the pace of a good year.
